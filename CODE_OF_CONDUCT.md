# Code of Conduct

Project participation should be respectful, constructive, and safe. Harassment, discrimination,
threats, sexualised conduct, deliberate intimidation, and disclosure of another person's private
information are unacceptable in project spaces.

Contributors should critique ideas and code rather than people, assume good faith while still
addressing concrete harm, respect privacy, and help maintain an accessible environment. Project
maintainers may edit, remove, or reject contributions and restrict participation when necessary
to protect the community.

Report conduct concerns privately to the repository owner through the contact method on the
owner's GitHub profile. Reports will be handled as confidentially as practical. Security reports
belong in the process described by `SECURITY.md`, not in public conduct reports.
