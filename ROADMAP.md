# Product Roadmap

The release sequence prioritises a dependable local core over feature count.

- **0.1 foundation:** typed package, capability registry, safe paths, CLI baseline, tests, CI,
  and legacy compatibility.
- **0.2 conversion core:** native converter contracts, richer Markdown profiles, validation,
  structured extraction, and batch conversion.
- **0.3 PDF toolkit:** tested page operations, metadata, images, compression, and security basics.
- **0.4 automation:** OCR adapters, persistent jobs, workflows, organisation, and watch folders.
- **0.5 interfaces:** PySide6 desktop shell and localhost FastAPI web adapter over shared services.
- **0.6 signing and distribution:** improved visual placement, evaluated cryptographic signing,
  platform packages, release provenance, and SBOMs.

Enterprise server work remains out of scope until local security, job isolation, and stable APIs
are proven. Milestones, exit criteria, risks, and relative effort are in
[`docs/planning/IMPLEMENTATION_ROADMAP.md`](docs/planning/IMPLEMENTATION_ROADMAP.md).
